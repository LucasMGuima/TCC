
# Conventional Commits

## Estrutura

```
<tipo>[escopo opcional]: <descrição>

[corpo opcional]

[rodapé opcional]
```

## Tipos

- **feat**: Uma nova feature
- **fix**: Uma correção de bug
- **docs**: Mudanças na documentação
- **style**: Mudanças que não afetam o significado do código (espaço em branco, formatação, ponto e vírgula, etc)
- **refactor**: Uma mudança de código que não corrige um bug nem adiciona uma feature
- **perf**: Uma mudança de código que melhora o desempenho
- **test**: Adicionando testes ou corrigindo testes existentes
- **chore**: Mudanças no processo de build ou ferramentas auxiliares e bibliotecas como geração de documentação
